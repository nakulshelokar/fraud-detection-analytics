# 🔐 Fraud Detection Analytics

## Project Overview

Fraud Detection Analytics is a Python and Machine Learning project designed to analyze financial transactions and identify potentially fraudulent activity.

The project combines data analysis, machine learning, and interactive visualization to help understand fraud patterns and suspicious transactions.

## Objectives

- Analyze transaction data
- Identify fraudulent transactions
- Calculate fraud rates
- Analyze fraud by location and device type
- Train a machine learning model
- Visualize fraud patterns
- Build an interactive dashboard

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit
- Plotly
- Machine Learning
- GitHub

## Machine Learning Model

The project uses a **Random Forest Classifier** to classify transactions as:

- Legitimate
- Fraudulent
